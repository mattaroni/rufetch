# RuFetch

A minimalistic <abbr>CLI</abbr> file downloader, powered by Rust.

## Usage

> [!NOTE]
> Be sure to have [Cargo](https://doc.rust-lang.org/cargo/getting-started/installation.html)
> installed.

Use the command below to compile and install the binary.

```
cargo install https://github.com/mattaroni/rufetch.git
```
